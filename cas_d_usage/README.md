# Les cas d'usage

Chaque dossier de ce répertoire est un **cas d'usage partenaire complet** — un îlot autonome contenant tout ce qu'il faut pour comprendre, rejouer et intégrer le parcours.

| Dossier | Contenu |
|---|---|
| [`🚢 /sanction`](./sanction/) | 🚢 Donner suite aux propositions de sanction |
| [`/_template`](./_template/) | 📦 Le gabarit — à copier pour créer un nouveau cas d'usage |

---

## Pour chaque cas d'usage

```
mon-cas-d-usage/
├── README.md                  la photo — le job to be done, le parcours, le démarrage
├── parcours.arazzo.yaml       la notice — l'orchestration, étape par étape
├── processus-metier/          le pourquoi — contexte, acteurs, règles de gestion
├── postman/                   le rejouable — collection prête à importer
```
