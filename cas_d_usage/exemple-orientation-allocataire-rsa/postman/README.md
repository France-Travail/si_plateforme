# Rejouer le parcours — collection Postman

> Quadrant : **Tutorial** — l'objectif est votre premier parcours réussi, sans écrire de code.

## Contenu

| Fichier | Rôle |
|---|---|
| `orientation-rsa.postman_collection.json` | Le parcours complet, une requête par étape, dans l'ordre de la notice — [X : à produire] |
| `orientation-rsa.postman_environment.json` | Les variables : URLs, identifiants à compléter — [X : à produire] |

## Rejouer en 3 gestes

1. Importer la collection et l'environnement dans Postman.
2. Renseigner vos identifiants dans l'environnement ([pré-requis d'accès](../README.md#démarrer)).
3. Lancer le Runner sur la collection : les 5 étapes s'enchaînent, chaque sortie nourrit l'entrée suivante.

> Les requêtes utilisent le jeu de données de référence (identifiants stables) : le parcours est rejouable à l'identique.
